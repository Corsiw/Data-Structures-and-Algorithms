# Доказательство
Для расстояния Левенштейна, докажи, что $ed_L(s_1,s_2) ≤ ed_L(s_1,s_3) + ed_L(s_3,s_2)$

По определению $ed_L(s_1, s_2)$ - минимальное число операций, чтобы превратить $s_1$ в $s_2$.

Пусть можем превратить $s_1$ в $s_3$ за $ed_L(s_1,s_3)$ операций, а $s_3$ в $s_2$ за $ed_L(s_3,s_2)$ операций.

Тогда можем превратить $s_1$ в $s_2$ за $ed_L(s_1,s_3) + ed_L(s_3,s_2)$.  
Но $ed_L(s_1,s_2)$ - минимум по всем путям превращения $s_1$ в $s_2$, в том числе и $ed_L(s_1,s_3) + ed_L(s_3,s_2)$.

Таким образом $ed_L(s_1,s_2) ≤ ed_L(s_1,s_3) + ed_L(s_3,s_2)$.
