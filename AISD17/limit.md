# Докажем, что Эйлеровых графов очень мало

$$\lim_{p \rightarrow \infty} \frac{|E(p)|}{|N(p)|} = 0$$

Всего графом с p вершинами:
$$|N(p)| = m = C_p^2$$

Граф эйлеров тогда и только тогда, когда:
1. Он связан,
2. Степень каждой вершины чётная

Оценим $|E(p)|$ сверху, для этого рассмотрим только второе условие, ведь первое только уменьшает число графов.

Для случайного графа и $N(p)$ степень фиксированной вершины четна с вероятностью $\frac{1}{2}$.

Знаем, что сумма степеней всех вершин всегда чётна, тогда условия чётности степеней линейно зависимы.
Следовательно, только p-1 условий остается.

Каждое из условий уменьшает число графов в два раза:
$$|{графы \, с \, чётными \, степенями}| = 2^{m-(p-1)}$$

Тогда:
$$\frac{|E(p)|}{|N(p)|} \le \frac{2^{m-(p-1)}}{2^m} = 2^{-(p-1)},$$

$$\lim_{p \rightarrow \infty} \frac{|E(p)|}{|N(p)|} = 0$$
