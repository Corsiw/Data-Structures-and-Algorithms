# Как построить минимальный остов?

## Алгоритмы

### $ALG_1$
Удаление ребра допустимо <=> оно не мост в текущем графе.

Если идти в порядке убывания весов, можно заменить алгоритм на обычный Краскал.

Удаление рёбер, если они не мосты <=>
Добавление рёбер по возрастанию, если они не образуют цикл.

То есть это просто Краскал.

Алгоритм Краскала - это жадный алгоритм для поиска минимального остовного дерева во взвешенном неориентированном графе.  
Его сложность $O(|E| \cdot \log |E|)$ - сложность сортировки рёбер.
Сложность работы DSU поглощается сортировкой - $O(|E| \cdot \alpha(|V|))$.

Код:
```c++
struct Edge {
    int u, v;
    int w;
};

class DSU {
public:
    DSU(int n);
    int find(int v);
    void unite(int a, int b);
};

vector<Edge> ALG_1(int n, vector<Edge>& edges) {
    sort(edges.begin(), edges.end(),
         [](const Edge& a, const Edge& b) {
             return a.w < b.w;
         });

    DSU dsu(n);
    vector<Edge> T;

    for (const Edge& e : edges) {
        if (dsu.find(e.u) != dsu.find(e.v)) {
            dsu.unite(e.u, e.v);
            T.push_back(e);
        }
    }

    return T;
}
```

### $ALG_2$
Идея алгоритма:
- Перебирать рёбра в случайном порядке
- Добавлять, если не образуется цикл
Это Краскал без сортировки.

Сложность шафла $O(|E|)$, она поглощается.  
Тогда сложность $O(|E| \cdot \alpha(|V|))$.
```c++
struct Edge {
    int u, v;
    int w;
};

class DSU {
public:
    DSU(int n);
    int find(int v);
    void unite(int a, int b);
};

vector<Edge> ALG_2(int n, vector<Edge> edges) {
    random_shuffle(edges.begin(), edges.end());

    DSU dsu(n);
    vector<Edge> T;

    for (const Edge& e : edges) {
        if (dsu.find(e.u) != dsu.find(e.v)) {
            dsu.unite(e.u, e.v);
            T.push_back(e);
        }
    }

    return T;
}
```

### $ALG_3$
Идея:
- Перебирать рёбра в произвольном порядке
- Добавлять
- Если образовался цикл - удалить из цикла самое тяжёлое ребро

Эффективная реализация через Link-Cut Tree

Link-Cut Tree - это структура данных для работы с динамическим лесом (набором деревьев), которая позволяет:

link(u, v) - соединить два дерева ребром  
cut(u, v) - удалить ребро  
connected(u, v) - проверить связность  
query(u, v) - агрегировать что-то на пути (например, максимум)  

Обычное дерево неудобно для частых изменений структуры
запросов "что на пути между u и v"

LCT решает это за счет Splay Tree:
Представляет дерево как набор предпочтительных путей,
а каждый путь хранит в виде splay-дерева.

За счёт splay-деревьев все операции работают за $O(log |V|)$ амортизированно.

Тогда алгоритм работает за $O(|E| \cdot \log |V|)$
```c++
// Примерная реализация для Node
struct Node {
    Node *left, *right, *parent;
    bool rev;

    int value;          // вес (для edge-узлов)
    int max_value;      // максимум в splay-поддереве
    Node* max_node;     // указатель на узел с максимумом

    int u, v;           // если это edge-узел
};

class LinkCutTree {
public:
    bool connected(int u, int v);
    std::pair<int, int> maxEdge(int u, int v);
    void link(int u, int v, int weight);
    void cut(int u, int v);
    void removeEdgeNode(int node)
};

vector<Edge> ALG_3(int n, vector<Edge>& edges) {
    LinkCutTree lct;
    vector<Edge> T;

    for (const Edge& e : edges) {
        if (!lct.connected(e.u, e.v)) {
            lct.link(e.u, e.v, e.w);
            T.push_back(e);
        } else {
            auto p = lct.maxEdge(e.u, e.v);
            if (p.first > e.w) {
                lct.removeEdgeNode(p.second);
                lct.link(e.u, e.v, e.w);
            }
        }
    }
    
    return T;
}
```

## Получаем ли минимальное остовное дерево

### $ALG_1$
`MST (Minimum spanning tree)`

Всегда строит MST, так как аналогичен алгоритму Краскала, только в обратном порядке.  
Более точно это Reverse-delete алгоритм. А он формирует MST
### $ALG_2$
Не всегда образует MST.  
Рёбра выбираются случайно, без учёта весов.

Контр-пример:
Допустим случайно включили A-C и B-D.
Тогда в зависимости от выбора следующего ребра (выбор случайный)
можем получить MST через A-B или не получить через C-D
```
A---B (1)
|   |
3   2
|   |
C---D (4)
```

### $ALG_3$
Да формируется.

Используется свойство цикла MST:  
`В любом цикле самое тяжёлое ребро не принадлежит MST.`

В алгоритме буквально используется это свойство:  
Если после добавления ребра получаем цикл, то удаляем самое тяжёлое ребро
